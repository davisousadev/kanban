# Kanban

Este é um projeto que fiz para aprender Vue 3 na prática. A ideia foi construir um kanban simples, com foco em entender a base da framework, organização de componentes e fluxo de dados entre as partes da aplicação.

Também usei o Pinia, que funciona como um compartilhador de contexto no Vue, para controlar parte do estado da aplicação de forma mais organizada.

Mesmo sendo um projeto pequeno, ele me ajudou a aprender bastante coisa importante sobre Vue, composição de componentes, estado global e estrutura de uma aplicação frontend.
